# Errow Lore Index

This directory is the repository-local index for Errow narrative canon.

## Current canon sources

### docs/lore/FOUNDATION.md

Authoritative scope:

- the Flow;
- the Signal;
- the break of the Signal;
- the diegetic meaning of solving a puzzle;
- the foundational narrative line;
- the OPEN questions and narrative constraints that protect future expansion.

This is currently the only dedicated narrative CANON source.

docs/lore/LORE-HANDOFF.md is continuation metadata, not canon.

Gameplay/product specs under docs/ and level labels in code describe mechanics and product behavior; they are not silently promoted to fictional-world canon.

## Canon states

Every future narrative assertion must distinguish:

- **CANON** — stable fictional-world fact.
- **RUMOR** — in-world claim that may be false, partial or contradictory.
- **OPEN** — intentionally unresolved question.

RUMOR must not become CANON without an explicit narrative decision. OPEN questions stay open until deliberately resolved.

## Current narrative boundary

The minimum premise is established, but deeper cosmology remains intentionally unresolved.

In particular, the repository does not yet establish:

- named characters;
- factions;
- named locations;
- a formal campaign chronology;
- the true nature of the Flow;
- the true nature or origin of the Signal;
- the identity of whoever or whatever caused the break;
- whether arrows possess literal consciousness;
- the player's diegetic identity.

## Adding a canon source

Create a lore document only when a real narrative wave justifies it, then add it to this index with its purpose and authoritative scope.

The standalone `lore` command must read this index and every source it names before changing narrative state.
